# 📍 2025 인천광역시 공공데이터 활용 경진대회
## 폴린(Fallin): 고령자 낙상 위험 예측 및 안전 경로 안내 서비스

### 📌 Project Vision
초고령 사회 진입에 따라 급증하는 노인 낙상 사고를 예방하기 위해, 단순 최단 경로가 아닌 **"최소 위험 경로"**를 제시하는 데이터 기반 공간정보 서비스를 기획하고 구현했습니다. 인천시의 지형, 조도, 기상 데이터를 융합하여 정밀한 낙상 위험 지초를 산출합니다.

### 🏆 주요 성과
- **주최:** 인천광역시
- **핵심 기술:** GIS 공간 분석, 몬테카를로 시뮬레이션 기반 위험도 산정, Folium 시각화.
- **데이터 활용:** 공공데이터포털(보행로, 등고선), 기상청 API, 도로 조도 CSV.

### 🛠️ 핵심 분석 혁신 (Analytical Innovation)
1. **정밀 지형 분석 (GIS Analytics):**
   - 국토지리정보원 등고선 데이터를 활용하여 **DEM(Digital Elevation Model) 보간** 및 경사도 계산.
   - 보행로 Shapefile과 결합하여 도로 단위의 평균 경사도(`mean_slope`) 산출.
2. **다중 변수 위험도 모델링:**
   - 실시간 기상(강수, 습도, 기온) + 야간 조도 + 지형 경사도를 결합한 **낙상 위험 점수(Fall Risk Score)** 알고리즘 설계.
   - 노인 통계(KOSIS) 기반의 가중치(Weight) 튜닝을 통해 모델의 현실성 확보.
3. **인터랙티브 공간 시각화:**
   - **Folium** 라이브러리를 활용하여 인천 전역의 보행로별 위험도를 3단계(낮음/보통/높음)로 시각화.
   - 사용자 위치 기반의 실시간 위험 정보 툴팁 제공.

### 📊 분석 ROI (Analytical Impact)
- **사회적 가치:** 최단 거리 대비 낙상 위험을 30% 이상 감소시킬 수 있는 안전 경로 가중치 알고리즘 제안.
- **확장성:** 단순 지도 서비스를 넘어 보호자 알림 및 지자체 제설/안전시설 우선 설치 지역 선정의 근거 데이터로 활용 가능.
